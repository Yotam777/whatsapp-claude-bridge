## מה הכלי עושה
- 💬 **שיחה עם Claude מווצאפ** — כותבים או מקליטים בקבוצת "Claude" הפרטית שלך; Claude עונה (👀 כשהגיע, ✅ כשנענה, קבצים חוזרים כקבצים מצורפים).
- 📝 **טיוטות במקום שליחה** — כל הודעה לאנשים אחרים הופכת לכרטיס טיוטה עם קישור, ואתה בודק ושולח. שליחה עצמאית רק באישור מפורש ולזמן מוגבל.
- 🛡️ **שמירה על החשבון** — קצב אנושי (3–7 שניות, "מקליד…", תקרה יומית) ועצירה אוטומטית כשווצאפ מגביל.
- 🎙️ **תמלול הקלטות** — כל הודעה קולית מתומללת במחשב (מודל עברית של ivrit-ai כברירת מחדל).
- 🔄 **סנכרון אמין** — עדכון מיידי, טיפול בכל הודעה פעם אחת בדיוק, מדיה נשמרת מיד (לא פגה), עריכות ומחיקות, סקרים והצבעות, איחוד אנשי קשר.
- 🖥️ **לוח בקרה** — `WhatsAppDash.exe`: זמן חיבור, השיחה שלך עם הכלי, מצב שליחה, טיוטות, תמלולים, עלויות ויומן. עובד בלי אינטרנט ובלי הסוכן. עברית/אנגלית, בהיר/כהה, עדכונים.
- 🔌 **שרת MCP ל-Claude Code** — חיפוש בהודעות ובתמלולים, סקרים, טיוטות, תגובות אימוג'י, שליחה עם ציטוט, הורדת מדיה ומצב.
- 💾 **גיבוי ובריאות** — גיבוי לילי, התראת Windows כשווצאפ מנותק, תקרת עלות יומית ל-Claude, תוספים לפרויקטים שלך.

## התקנה (Windows 10/11)
צריך: [uv](https://docs.astral.sh/uv/) ו-[Claude Code](https://docs.claude.com/claude-code) (לשיחה מווצאפ).

```bat
git clone https://github.com/WallaBoohi/whatsapp-claude-bridge.git
cd whatsapp-claude-bridge
setup.cmd
```

האשף מקשר את הווצאפ (QR), יוצר לך אוטומטית את קבוצת הבקרה "Claude" שבה רק אתה (או, אם תעדיף, מזהה קבוצה שיצרת וכתבת בה `claude-setup`), כותב הגדרות, מתקין רכיבים,
רושם את שרת ה-MCP, מפעיל הכול בכניסה ל-Windows, מתקין את לוח הבקרה ומריץ בדיקה עצמית.

### הוספה ל-Claude Code כתוסף

אחרי `setup.cmd`, בכל סשן של Claude Code:

```text
/plugin install whatsapp-bridge --marketplace WallaBoohi/whatsapp-claude-bridge
```

כשתתבקש, בחר בשדה **WhatsApp bridge folder** את התיקייה שבה הרצת את `setup.cmd`.

## שימוש יומיומי
- **שיחה:** כותבים בקבוצת Claude. התשובות מגיעות בכתב נטוי עם 🤖, כציטוט של ההודעה שלך — כך קל להבדיל ביניכם. הודעה שמתחילה ב-`!` עוקפת את תקרת העלות היומית, ו-`!!!` מבטלת אותה לשעה שלמה.
- **מצב שליחה:** בלוח הבקרה — "טיוטות בלבד" / "שליחה עצמאית לשעה", השהיה וחידוש.
- **בדיקה עצמית:** `uv run python -X utf8 tools/selftest.py` (עם `--quiet` לא נשלח כלום).
- **הוראות אישיות ל-Claude:** `agent/home/CLAUDE.md` (לא עולה לגיט).
- **תוספים:** קובץ פייתון עם `setup(agent)` ברשימת `"plugins"` ב-`agent/config.json`.
